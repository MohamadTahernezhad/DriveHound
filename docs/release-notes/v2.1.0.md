| `DriveHound-Portable-2.1.0.exe` | Portable: no installation, runs from any folder or USB stick |

Windows 10 / 11 (64-bit). The files are not code-signed yet, so on first run Windows SmartScreen may show
*"Windows protected your PC"* → **More info** → **Run anyway**. Compare the file with `SHA256SUMS.txt` if you want to verify it.

## What's new in 2.1

- 🐕 **New name: DriveHound** (formerly Disk Insight). Your settings, history, saved AI keys and right-click menu carry over automatically.
- 🤖 **Any AI model.** Use Claude, OpenAI, Google Gemini, OpenRouter, Groq, DeepSeek, Mistral, local Ollama / LM Studio or any OpenAI-compatible endpoint. Add several providers and pick the active one. Keys are encrypted per provider, there is a connection test, and consent is asked per provider.
- 🧹 **Clean uninstall.** The uninstaller removes the Explorer right-click menu and the startup entry.
- 🧪 **More tests.** End-to-end tests now run a real scan, the duplicate finder, monitoring and the AI provider flow.
- 🔒 **Hardening.** The UI is served from a private `app://` origin, so `file://` privileges can be disabled.

## Fixes

- Scan results did not reach the UI in 2.0. Now covered by an end-to-end test.
- Filter bar icons overflowed their controls.
- Opening the app from the Explorer menu during startup could overwrite settings.

## Removed

- The "Dev projects" page. Build-artifact detection (node_modules, caches, …) is still part of the other views.
