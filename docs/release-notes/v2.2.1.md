## Download

| File | What it is |
|---|---|
| **`DriveHound-Setup-2.2.1.exe`** | Installer (recommended): Start-menu shortcut, auto-updates, clean uninstall |
| `DriveHound-Portable-2.2.1.exe` | Portable: no installation, runs from any folder or USB stick |

**On 2.2.0 or older?** Install this version once from this page. Older versions show no download progress, so their update button looks like it does nothing. From 2.2.1 on, updates install from inside the app.

## New

- **A proper update experience**: when a new version is out, a button appears at the top of the window. The update dialog shows what changed, a live progress bar (size, speed, time left) and "Restart & install". The app installs the update and opens again by itself.

## Fixed

- "Download & install" looked like it did nothing: the download ran with no progress and errors were hidden.
- Dropdown options were unreadable in the dark theme.
- The delete-method buttons in Settings wrapped onto two lines.

## دانلود

- **`DriveHound-Setup-2.2.1.exe`**: نسخه‌ی نصبی (پیشنهادی)
- `DriveHound-Portable-2.2.1.exe`: نسخه‌ی قابل‌حمل، بدون نصب

**نسخه‌ی ۲.۲.۰ یا قدیمی‌تر دارید؟** این نسخه را یک بار از همین صفحه نصب کنید. نسخه‌های قبلی پیشرفت دانلود را نشان نمی‌دادند و به‌نظر می‌رسید دکمه‌ی آپدیت کار نمی‌کند. از ۲.۲.۱ به بعد آپدیت‌ها از داخل خود برنامه نصب می‌شوند.

## جدید

- ✨ **به‌روزرسانی حرفه‌ای**: وقتی نسخه‌ی جدید منتشر شود، دکمه‌ای بالای پنجره ظاهر می‌شود. پنجره‌ی آپدیت تغییرات، نوار پیشرفت زنده (حجم، سرعت، زمان باقی‌مانده) و دکمه‌ی «راه‌اندازی مجدد و نصب» را نشان می‌دهد. برنامه خودش نصب می‌کند و دوباره باز می‌شود.

## رفع مشکل

- 🐞 دکمه‌ی «دانلود و نصب» ظاهراً کاری نمی‌کرد: دانلود بدون نمایش پیشرفت انجام می‌شد و خطاها پنهان می‌ماندند.
- 🐞 گزینه‌های منوهای کشویی در تم تیره خوانا نبودند.
- 🐞 دکمه‌های «روش پیش‌فرض حذف» در تنظیمات دوخطی می‌شدند.
