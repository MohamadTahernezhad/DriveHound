# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and patient. People here write in Persian and English, with different levels of experience.
- Critique code and ideas, not people.
- No harassment, insults, discrimination or sharing other people's private information.
- Assume good intent, and help newcomers find their way.

## Reporting

If someone behaves unacceptably, contact the maintainer privately through the e-mail on their GitHub profile,
or use GitHub's **Report content** option. Reports are handled confidentially.
Maintainers may remove comments, commits or issues that break this code, and may block repeat offenders.
